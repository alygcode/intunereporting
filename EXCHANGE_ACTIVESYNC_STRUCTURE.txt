Microsoft Graph API Endpoints
==============================

1. GET /deviceManagement/managedDevices
   ├── Purpose: Fetch all managed mobile devices
   ├── Filters: managementAgent eq 'eas' or 'easMdm'
   └── Returns: Device list with Exchange data

2. GET /deviceManagement/deviceCompliancePolicies
   ├── Purpose: Get all compliance policies
   └── Returns: Policy list

3. GET /deviceManagement/deviceCompliancePolicies/{id}/deviceStatuses
   ├── Purpose: Get device statuses for policy
   └── Returns: Status list per policy

4. GET /deviceManagement/managedDevices/{id}/deviceCompliancePolicyStates
   ├── Purpose: Get policy states for device
   ├── Expand: settingStates
   └── Returns: Detailed compliance state


Report Methods Overview
========================

execute()
├── Runs all 4 reports in parallel
├── Generates comprehensive summary
└── Returns: ReportData with metadata

getActiveSyncPolicyCompliance()
├── ConfigMgr Report #8
├── Fetches: Devices + Policies + Statuses
├── Aggregates: By access state and platform
└── Returns: ActiveSyncPolicyComplianceSummary[]

getInactiveMobileDevices(threshold, options?)
├── ConfigMgr Report #15
├── Calculates: Days since last sync
├── Filters: By threshold and options
└── Returns: InactiveMobileDevice[]

getAllMobileDeviceComplianceDetails(options?)
├── ConfigMgr Report #21
├── Fetches: Device details + Policies + Actions
├── Processes: In batches of 30
└── Returns: MobileDeviceComplianceDetails[]

getMobileDeviceSettingsSummary()
├── ConfigMgr Report #34
├── Aggregates: Settings across policies
├── Samples: 10 devices per policy
└── Returns: MobileDeviceSettingsSummary[]

Usage Examples
==============

Basic:
  const report = new ExchangeActiveSyncReports(graphClient, config);
  const data = await report.execute();
  await report.exportToJson(data, './output');

Filtered:
  const inactive = await report.getInactiveMobileDevices(30, {
    platform: 'iOS',
    exchangeAccessState: ExchangeAccessState.BLOCKED
  });

Advanced:
  const [policies, settings] = await Promise.all([
    report.getActiveSyncPolicyCompliance(),
    report.getMobileDeviceSettingsSummary()
  ]);
